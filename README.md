# Kristian Tokos - ICSI418Y - PA1

### PA1 - Task List

This application allows the user to add a task with a priority of their choice. It also allows the user to complete or delete the task. Once the user completes a task, the task is added to the completed task list.

### Running Instructions

This application can be ran by hosting a live server within the development environment. It is not hosted anywhere.
